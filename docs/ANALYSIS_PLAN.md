# Suggestion Discovery Lab — Pilot 1.0 analysis plan

**Prepared 16 November 2026 · Draft for owner/statistical review · Not a preregistration.** Development data and examples have already informed the design. This plan defines a prospective pilot cohort; earlier data remain exploratory and separate. Institutional/ethics and privacy arrangements still govern collection.

**Question and outcome.** Compare resonance across two targets (sensory/discriminative; affective/motivational) and three forms (Direct; literal Imagery; Metaphorical), including their interaction. Primary outcome: the exploratory, unvalidated 0–10 resonance question (`resonance-1`; 0 Not at all, 10 Very much). This measures connection/relevance, not therapeutic efficacy; comparisons concern generated suggestion packages, not isolated psychological mechanisms. Intensity changes are secondary descriptive observations without an untreated comparator.

**Cohort and exposure window.** Include `pilot-1.0` sessions with protocol `physical-targets-2x3-v5`, prompt `physical-target-suggestions-7`, resonance-1 and balanced-text-1. For each participant ID, select its earliest eligible session by creation timestamp, breaking ties by session ID; analyse rounds 1–3, including partial sessions/rounds and all available numeric responses. Do not require completion or replace an early stopped session with a later successful one. Report IDs, sessions and ratings separately; anonymous IDs do not guarantee unique individuals.

**Fixed delivery.** Six conditions once per round; uniformly sampled alternating-target order (72 orders). Eyes closed while listening; no automatic next playback. Final recordings have four sentences and 65–85 words, including the deduplicated sensory closing. Same voice/requested speed (0.8), 3-second lead-in, 4-second intersentence pauses and standard end tone. Approximate duration target: 55–70 seconds including silence/tone; record actual duration and flag outliers without padding, time-stretching or automatic exclusion. Preserve requested settings, returned model IDs and exact text. Any material change needs a new version/cohort; do not pool model/configuration changes without reporting them.

**Analysis.** Start with 0–10 distributions, missing/unable counts and participant-balanced category means. Proposed inferential analysis: an ordinal mixed model with target, form, target×form, round (1–3) and position (1–6) as categorical fixed effects and participant intercepts. Assess sparsity, convergence and model assumptions with a statistician. If unsuitable, report descriptive within-participant contrasts and participant-level bootstrap intervals, with the contributing IDs for each contrast. Do not treat ratings as independent people or select an analysis because it produces significance. All-session/all-round analyses are secondary and must account for sessions within participants. Report uncertainty and all six cells; avoid a post-hoc “high resonance” cutoff.

**Missingness and quality.** Keep zero, Unable to rate and missing separate; neither latter is imputed as zero. Report noncompletion by round/position and reasons when available, without assuming missingness is random. Review duration, text length, duplicates, randomisation and playback anomalies; flags are not automatic exclusions. Independently review a seeded balanced sample (up to five suggestions per cell) for perceived target/form, imagery comparisons, clarity, repetition and safety; retain disagreements and adjudication separately.

**Before collection/analysis.** Owner must set an approved recruitment target or collection end date and confirm this plan; no power or stopping threshold is invented here. Record changes and approval/registration dates prospectively. Before the final extract, pause collection, settle in-flight writes, export every page with the same cutoff, archive raw CSVs and record exclusions/deviations. The dashboard is descriptive and live, not a frozen analysis dataset.

References: [COS preregistration](https://www.cos.io/initiatives/prereg); [within-participant analysis guidance](https://www.bmj.com/content/366/bmj.l4378).
